## Documentation Links

When explaining any technical concept, library, function, or model, include inline links to relevant docs at the point of first mention. Priority order:

1. Official docs (e.g. pandas.pydata.org, scikit-learn.org, docs.python.org)
2. High-quality visual explainers (e.g. StatQuest, 3Blue1Brown)
3. Well-regarded articles (e.g. Towards Data Science, Real Python)

If recommending one approach over another, link the alternatives too. Include foundational papers or resources where relevant.
